Abstract

Transforming multi-camera images into a bird's-eye-view (BEV) or 3D voxel representation is a prerequisite for structured perception in autonomous driving and robot navigation. Published implementations of the leading methods — Lift-Splat-Shoot, BEVFormer, TPVFormer — rely on compiled CUDA kernels and heavy mm-family dependencies, making them hard to run, modify, or port to new hardware.

Halos-lift re-implements seven lifting architectures in pure PyTorch using only F.grid_sample, F.interpolate and batched attention, with no custom ops, no mmcv, and no mmdet3d. All lifters share a BaseLifter.forward(features, cameras) → (B, C, X, Y) interface and can be swapped into the same BEVSegmentationModel or TPVFormer pipeline. A built-in geometric verifier trains each lifter end-to-end on procedurally rendered synthetic scenes with random camera rigs, then checks three conditions: it must beat a geometry-free baseline, its mIoU must collapse when the rig is rotated 90°, and its loss must decrease. All seven pass.

Highlights

Zero compiled ops

Deformable attention, voxel pooling, LSS frustum splatting — all via F.grid_sample and batched matrix ops. Runs on CPU, CUDA and Apple Silicon MPS.

One interface, seven lifters

LIFTERS.build("lift_splat", grid, in_channels, out_channels) — swap any lifter into any model without touching training or evaluation code.

TPVFormer support

Three orthogonal planes (xy, xz, yz), cross-view hybrid attention, per-plane image cross-attention, auxiliary per-plane heads, 3D occupancy and point-cloud queries.

Geometry verifier

Trains every lifter on synthetic scenes, then rotates the camera extrinsics 90° — a geometric lifter must fail. Outputs a GIF and a JSON report.

Analytic tests

Pixel-ramp and depth-ramp probes verify lifting is exact. Equivariance test checks rig rotation → volume rotation. All ops checked with gradcheck.

Training stages

Three-phase configs: synthetic pretrain → nuScenes / Waymo mid-train → Occ3D / BEV-seg post-train, all in configs/ with inherits: YAML.

Quick start

pip install "git+https://github.com/basaanithanaveenkumar/Halos-lift"
# or: uv add "halos-lift @ git+https://github.com/basaanithanaveenkumar/Halos-lift"
import torch
from lifting import GridSpec, Cameras, build_bev_model

grid = GridSpec(x_bounds=(-50, 50), y_bounds=(-50, 50),
                z_bounds=(-2, 2), resolution=(200, 200, 4))

# BEV semantic segmentation — swap any lifter name
model = build_bev_model("bevformer", grid, num_classes=6, image_size=(224, 400), num_cameras=6)
logits = model(images, cameras)["logits"]   # (B, 6, 200, 200)
# Use any lifter standalone with your own encoder
from lifting import LIFTERS
lifter = LIFTERS.build("lift_splat", grid=grid, in_channels=128, out_channels=128)
bev = lifter(features, cameras)             # features: list of (B, N, C, H_l, W_l)
# Run the geometric verifier (~5 min, laptop CPU)
lifting-verify --gif verification.gif --json report.json
